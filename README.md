# PlantDb — premium bilingual botanical collection

Design preview for the Maejo University plant / animal / research variety collection
(legacy Joomla + ZOO database being modernised).

> **This is a design-review preview.** Content is public-safe demo material, the site is
> not published, and no production data is included. The build is not connected to any
> database.

## Stack

- **Astro 5 + TypeScript**, static output (`dist/`), no UI framework, no CSS framework
- GitHub Pages project site: base path `/PlantDb/`
- Only runtime dependency: Astro. `@astrojs/check` + `typescript` are devDependencies.

## Commands

```bash
npm install
node scripts/gen-routes.mjs     # regenerate the bilingual route tree (mechanical, kept in sync)
npm run dev                     # http://localhost:4321/PlantDb/
npm run build                   # static build → dist/ (60 pages)
npx astro check                 # types + templates
node --experimental-strip-types scripts/test-i18n.mjs   # TH/EN dictionary parity
node scripts/qa-site.mjs        # functional QA against dist/ (links, lang, hreflang, heading order,
                                #   locale parity, fallback policy, demo provenance, sitemap)
node scripts/lighthouse.mjs --urls=full --threshold=90   # Lighthouse gate (TH/EN × desktop/mobile)
bash scripts/shots.sh           # screenshots at 1440 / 834 / 390 px, both locales
```

## Bilingual contract (short version)

- Default locale **Thai** at `/PlantDb/`, English at `/PlantDb/en/`; switcher in the header
  (and in the mobile sheet) preserves the current query string.
- All UI copy lives in `src/i18n/ui.ts`; a missing key in either locale is a **TypeScript error**
  and the parity test fails.
- Botanical records carry per-locale values with review status and provenance. A missing
  translation is shown as the source-language text **with a badge** — records are never hidden
  and machine text is never presented as an approved translation.

## Safety

No production access, no database writes, no raw production data, no credentials, no unapproved
media. Placeholder artwork is generated inline SVG, so no image can be broken or unlicensed.
